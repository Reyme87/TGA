## О проекте
 
TG Analyser — десктопное приложение для парсинга и анализа контента телеграм-каналов. После авторизации пользователь видит в интерфейсе полный список каналов, на которые он подписан, и может выбрать любой из них для анализа. Приложение парсит последние 100 постов канала и для каждого выводит автора, текст сообщения, количество реакций и просмотров — а также тематику, определённую подключённой моделью классификации данных.
 
Идея проекта в том, чтобы дать быстрый способ понять, о чём вообще пишет канал, не листая вручную десятки постов — модель сама раскладывает их по темам, а численные метрики (реакции, просмотры) помогают сразу увидеть, какой контент заходит аудитории лучше.
 
Проект выполнен в рамках проектно-технологической практики 2 курса по специальности 09.03.01 «Информатика и вычислительная техника».
 
## Как это работает
 
Приложение состоит из двух основных частей:
 
1. **Список каналов пользователя** — над каждым каналом отображается его название и тег автора.
2. **Список сообщений из выбранного канала** — карточки постов с полным набором характеристик.
Во время парсинга текст каждого поста передаётся обученной модели классификации, которая относит его к одной из шести тематик:
 
- Новости и политика
- Спорт
- Развлечения
- Здоровье
- Образование
- Другое
  
Для каждого поста в интерфейсе показаны:
 
- Тематика
- Текст сообщения
- Количество реакций
- Количество просмотров
  
Внизу списка есть кнопка «Извлечь данные» — по нажатию все посты из текущего канала сериализуются в json-файл, который можно использовать для дальнейшего анализа за пределами приложения.
