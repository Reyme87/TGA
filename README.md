## О проекте

Приложение представляет собой парсер телеграм-каналов с подключенной моделью классификации данных для распределения постов по тематикам. После авторизации пользователю выводятся в графическом интерфейсе все телеграм-каналы, на которые он подписан. Далее, из выбранного пользователем тг-канала парсятся последние 100 постов, в которых выводится информация об авторе, сообщении поста, количестве реакций и количестве просмотров, а также тематика поста, определённая моделью классификации данных.  
Проект был выполнен в качестве практического задания на проектно-технологической практике 2-го курса по специальности 09.03.01 (информатика и вычислительная техника).

## Схема приложения

**Приложение состоит из 2-ух основных частей:**  
1. *Список каналов пользователя*  
2. *Список сообщений из выбранного канала*  

**Над каждым каналом располагается панель, на которой отображается название телеграм-канала и его тег (автор).**  
**Во время парсинга постов сообщения из них передаются обученной модели классификации данных, которая определяет одну из 6 следующих тематик:**
- *Новости и политика*  
- *Спорт*  
- *Развлечения*  
- *Здоровье*
- *Образование*
- *Другое*

**В каждом посте приведена информация по следующим характеристикам:**  
- *Тематика*  
- *Сообщение*  
- *Количество реакций*  
- *Количество просмотров*  

**В самом низу располагается кнопка "Извлечь данные", нажатие на которую приводит к сериализации данных из текущего канала в json-файл.**
